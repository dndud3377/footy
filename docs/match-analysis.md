# 경기 분석 지침 (Claude용)

"오늘 경기 분석해줘", "라인업 넣어서 다시 돌려줘", 예약 작업의 일일 리포트는 모두 이 지침을 따른다.

## 범위

- **"오늘 경기"** = KST 정오 ~ 다음날 정오에 킥오프하는 5대 리그 + 챔스 경기 (`data/processed/fixtures.csv`의 `kst_kickoff`).
- 예측 대상: 승·무·패 확률 + 가장 가능성 높은 정확한 스코어.

## 절차

1. 저장소 최신화 → `data/ingest_report.md`로 데이터 상태 확인 (오류·지연이 있으면 리포트 상단에 명시).
2. `predictions/YYYY-MM-DD.json`에서 footy 수치를 읽는다 (통계 모델·ML 둘 다).
   - footy 결과가 없으면 웹 정보만으로 추정하고 "모델 수치 없음"을 명시한다.
3. 경기별 웹 확인 — **구단·리그 공식 발표 우선**, 그다음 주요 언론:
   - 부상·징계·복귀, 예상 라인업, 감독 발언, 로테이션 가능성, 일정 부담, 동기(순위 경쟁·탈락 확정 등)
4. **보정** — 웹 정보가 모델이 반영하지 못한 사실을 담을 때만 확률을 조정한다.
   - 결과별 최대 **±5%p**, 세 확률 합 100% 유지, 근거를 한 줄로 적는다.
   - 원본과 보정본을 **항상 함께** 표시한다.
5. **신뢰도 0~100** — 데이터 완결성, 모델 간 일치도, 라인업 확정 여부, 변수(주전 결장 불확실 등)를 반영. 산정 근거를 짧게 적는다.
6. 리포트 작성 → 채팅에 요약 + `reports/YYYY-MM-DD.md` 저장·커밋.

## 리포트 형식 (경기당)

```
### [대회] 홈 vs 원정 — KST 킥오프
| | 홈승 | 무 | 원정승 | 예상 스코어 |
| 통계 모델 | | | | |
| ML | | | | |
| 보정본 | | | | |
신뢰도: NN/100 — 근거
핵심: 2~4줄 해설 (전력 차, 폼·xG 흐름, 결장자, 전술 매치업)
보정 근거: … (없으면 "보정 없음")
```

## 라인업 재분석

- 확정 라인업이 나오면 **해당 경기 전체를 재분석**한다 (부분 수정 아님).
- 결장·깜짝 선발 선수의 영향은 `players.csv`의 분당 xG·xA·xGChain으로 근거를 댄다.
- 같은 날 리포트 파일에 "라인업 반영" 섹션으로 덧붙이고 이전 수치도 남긴다.

## 경기 후

- 적중 여부(승무패·정확 스코어)를 기록한다 — 2단계 이후 `eval/ledger.csv`에 Actions가 자동 기록하고, Claude는 보정본 적중 여부와 메모를 남긴다.
- 배당률은 어떤 근거로도 쓰지 않는다.
